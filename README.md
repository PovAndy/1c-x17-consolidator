# 1c-x17-consolidator

Публичный исходный репозиторий обработки 1С «ВыгрузкаЗагрузкаДанныхXMLАдаптивная» и проверок, связанных с исправлением ошибок проекта 1С x17.

English version: [README.en.md](README.en.md).

## Версия и границы публикации

- Исходная версия обработки: **v25-123.10**.
- Публичная версия GitHub: **v25-123.10-public**.
- Публикация содержит только исходники обработки, безопасный synthetic fixture, статические тесты и двуязычную документацию.
- Production registry, базы 1С, архивы, логи, дампы, generated EPF/ERF, ключи, токены, пароли, конфиденциальные данные и полные параметры рабочей среды не публикуются.
- Полная рабочая среда ведётся отдельно в [1c-nexus-infra](https://github.com/PovAndy/1c-nexus-infra); этот репозиторий её не заменяет.

## Что опубликовано

- `[18.8]` — guarded пакетное исправление READY-нумерации с защитой номеров документов открытия лицевых счетов и постконтролем.
- `[18.12]` — ReadOnly-аудит READY-нумерации с проверкой структуры, UUID, дат, номеров и MD5.
- `[25.4]` — последовательный конвейер исправления блокеров обновления 36.14 с остановкой при ошибке и отдельными транзакциями этапов.
- `src/` — XML/BSL-исходники внешней обработки и формы.
- `scripts/` — только выбранные статические тесты и read-only контракты для перечисленных исправлений.
- `src/.../Templates/ПланАудитаREADYНумерации12305/Ext/Template.txt` — три полностью синтетические строки; это не выгрузка из рабочей базы.

Публичный fixture намеренно не является production registry. Проверки `[18.8]` и `[18.12]` работают fail-closed при несовпадении fixture или контура; наличие этого репозитория не является разрешением на запись в рабочую базу.

## Проверки публикации

Для версии выполняются `epf-validate`, `form-info`, `form-validate`, scoped static tests, `py_compile`, `git diff --check`, проверка секретов и post-push-аудит SHA/тега/версии. Designer build и live execution не заявляются без отдельного доказательства.

Подробности: [V25-123.10 release notes](docs/V25-123.10_RELEASE_NOTES_2026-08-22.md) и [контур публикации](docs/GITHUB_PUBLISH_SCOPE_2026-08-22.md).

## Публикационная безопасность

Перед каждым обновлением проверяется allowlist путей. Запрещены архивы, базы и дампы 1С, generated artifacts, сырые XML/CSV-выгрузки, журналы, скриншоты, персональные и производственные данные, секреты и credential-bearing command lines, реальные хосты/имена баз/порты/endpoint-ы, абсолютные пути, `.env`, виртуальные окружения, локальные индексы/RAG и полные параметры рабочей среды.
