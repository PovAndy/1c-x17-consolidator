# EPF-019

## Goal
Select and apply only the useful skills from `1c-ai-development-kit` to reduce code mistakes, token usage and workflow noise in EPF1129.

## Scope
- Review repository skills against current project workflow
- Install only low-dependency, high-value skills
- Integrate accepted skills into project runbook and setup

## Out of Scope
- Full adoption of the whole kit
- MCP-dependent skills not supported by the current stack
- Replacing existing `cc-1c-skills` where they already fit well

## Acceptance
- Selected skills are installed locally
- Runbook/setup document mandatory routing for them
- Explicit non-adoption is recorded for incompatible skills
