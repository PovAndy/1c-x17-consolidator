## Как работать с этим хвостом

1. Работать только на свежей базе, где уже применён `v25-118.32`.
2. Сначала закрывать строки из `икХарактеристикиПрочихОбъектов`.
3. Затем закрывать строки из `икХарактеристикиОбъектовУчета`.
4. Подставлять только те характеристики, смысл которых очевиден по карточке прибора, объекта или по чистой районной базе.
5. Если смысл характеристики неочевиден, не угадывать. Такой случай лучше оставить на отдельную ручную сверку.
6. После закрытия хвоста прогнать только контрольную диагностику broken refs.

## Как понять, к какому ЛС относится строка

### Для `икХарактеристикиПрочихОбъектов`

Здесь в нашем broken-логе обычно виден не сам ЛС, а объект прибора или его состояние:
- `ХВС`
- `ХВС (ул)`
- `ХВС 1`
- `хвс (дом)`
- `снят`
- `откл`

Это значит:
1. прямого номера ЛС в `x17_broken.csv` для этих строк нет;
2. ЛС нужно искать через карточку прибора или узла учета.

Практический порядок:
1. открыть карточку ЛС;
2. перейти на вкладку `Приборы учета`;
3. найти прибор с нужным типом:
   - `ХВС`
   - `ХВС (ул)`
   - `ХВС 1`
   - `хвс (дом)`
4. открыть карточку прибора;
5. на вкладке характеристик прибора найти значение из этой таблицы:
   - например `920269`, `7006062`, `4170684`, `АА 0930036`;
6. после этого станет понятно, к какому ЛС относится конкретная строка.

Иными словами:
- для `икХарактеристикиПрочихОбъектов` в руководстве ниже мы указываем семейство прибора и значения;
- сам ЛС определяется через карточку прибора в базе.
