# v25-123.10-public — Release notes / Примечания к выпуску

## Русский раздел

### Версия и область

- Исходная версия обработки: `v25-123.10`.
- Публичный GitHub-тег: `v25-123.10-public`.
- Удалённый baseline до обновления: `v25-123.03`.
- Репозиторий: `PovAndy/1c-x17-consolidator`.

Это ограниченная публикация исходников и документации по исправлению ошибок 1С x17. Полная рабочая среда остаётся в отдельном `1c-nexus-infra`.

### Изменения

- `[18.8]` — guarded пакетное исправление READY-нумерации; номера документов `икОткрытиеЛицевогоСчета` защищены, после записи предусмотрен постконтроль.
- `[18.12]` — ReadOnly-аудит с fail-closed проверками структуры, UUID, дат, номеров, дублей и контрольных сумм.
- `[25.4]` — последовательный pipeline `[24.3] -> [24.5] -> [24.7] -> [24.1]` с остановкой при ошибке и отдельными границами транзакций.
- Обновлены XML-метаданные, форма, диспетчеризация и статические тестовые контракты.
- Производственный READY-реестр заменён на три синтетические строки. Production UUID/даты/номера в fixture отсутствуют.

Проверки выполняются на clean public tree. Они не доказывают Designer build, работу через COM, исполнение в рабочей базе или разрешение на production-запись.

Критик подтвердил bounded-фрагменты `[18.8]` и `[18.12]`. Для `[25.4]` статический контракт проходит; отдельное runtime-доказательство обработки исключений оркестратора и изоляции транзакций дочерних шагов не получено и должно выполняться в приватном контуре.

### Исключения

В публикацию не входят базы 1С и дампы, архивы, generated EPF/ERF, логи, сырые выгрузки, RAG/индексы, виртуальные окружения, ключи/токены/пароли, конфиденциальные данные и полные параметры рабочей среды.

## English section

### Version and scope

- Processor source version: `v25-123.10`.
- GitHub public tag: `v25-123.10-public`.
- Remote baseline before the update: `v25-123.03`.
- Repository: `PovAndy/1c-x17-consolidator`.

This is a scoped source-and-documentation publication for 1C x17 error fixing. The complete working environment remains in the separate `1c-nexus-infra` repository.

### Changes

- `[18.8]` — guarded batch READY-numbering repair; `икОткрытиеЛицевогоСчета` document numbers are protected and post-control is required.
- `[18.12]` — ReadOnly audit with fail-closed checks for structure, UUIDs, dates, numbers, duplicates, and checksums.
- `[25.4]` — sequential `[24.3] -> [24.5] -> [24.7] -> [24.1]` pipeline with stop-on-error and separate transaction boundaries.
- Updated XML metadata, form, dispatching, and static test contracts.
- The production-derived READY registry was replaced with three synthetic rows. No production UUID/date/number data is included in the fixture.
