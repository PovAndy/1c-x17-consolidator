# Broken refs pass `v25-120.19`

## Scope

Целевой corrective-pass только для одного broken key:

- `93b45ce42a229ae211ef757e47ee586b`
- слой: `икХарактеристикиОбъектовУчета`
- семейство: `poliv50`
- целевой live target: `000000269 :: Поливная площадь з/у (норматив Волг. обл.)`

## Что изменено

1. В built-in карте восстановления уточнён target:
   - описание: `Поливная площадь з/у (норматив Волг. обл.)`
   - код: `000000269`
2. В object-account резолвере восстановление по описанию теперь учитывает `target_code`, а не отбрасывает его.
3. Обновлён внешний `context/recovery/other-pvh/out/restore_map.csv`, потому что сценарий `fix-other-chars` по умолчанию читает именно его, если файл существует.

## Почему это нужно

До `120.19` строка карты для ключа `93b45ce42a229ae211ef757e47ee586b` не содержала ни кода, ни live target ref. Для `икХарактеристикиОбъектовУчета` это приводило к неоднозначному/пустому разрешению, потому что резолвер игнорировал `target_code`.

## Ожидаемый результат

До фикса:
- `битых ссылок в характеристиках: 37`
- все оставшиеся строки сидят на broken key `93b45ce42a229ae211ef757e47ee586b`

После успешного прохода:
- `битых ссылок в характеристиках: 0`
- `Восстановлено строк: 37`
- в ошибках карты не остаётся строки `не удалось разрешить target для ключа 93b45ce42a229ae211ef757e47ee586b`

## Ручной порядок проверки

1. Открыть `compiled.epf` версии `v25-120.19`.
2. Убедиться, что путь к карте восстановления прочих характеристик указывает на актуальный `restore_map.csv`.
3. Выполнить:
   - `Диагностика прочих характеристик`
   - `Восстановить прочие характеристики`
4. Снять итоговый отчёт.

## Что считать успехом

1. В разделе карты:
   - `Готовых замен` увеличилось минимум на 1 для broken key `93b45ce42a229ae211ef757e47ee586b`
2. В контроле после обработки:
   - `битых ссылок в характеристиках: 0`
3. Нет регресса по ранее закрытому блоку `Характеристики помещения`.

## Известное ограничение

Штатный autorun на `x17_pg2` в этой среде может зависать до чтения `job.json` на стороне 1С. Это инфраструктурное ограничение запуска server-base hidden `/Execute`, а не дефект самого corrective-pass.
