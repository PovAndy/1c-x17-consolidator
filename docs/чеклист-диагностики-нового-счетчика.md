# Чек-лист диагностики ЛС: новый счетчик не участвует в начислениях

## Цель

Этот чек-лист нужен для разбора сценария:

1. на ЛС установили новый счетчик;
2. абонент несколько месяцев не передавал показания;
3. начисление шло по норме или среднему;
4. затем абонент передал показания;
5. в `x17` перерасчет и корректное начисление не происходят.

Работаем не по всей базе сразу, а по одному конкретному ЛС до полного понимания причины.

## Что взять перед началом

1. проблемный ЛС в `x17`;
2. аналогичный рабочий ЛС в чистой `x1`, где такой сценарий отрабатывает правильно;
3. период, за который не идет перерасчет;
4. номер услуги, по которой должен считаться новый счетчик;
5. документы:
   - замена или смена статусов прибора;
   - ввод начальных показаний;
   - ввод текущих показаний;
   - начисление или перерасчет.

## Как формулировать причину

После проверки причина обычно попадает в одну из групп:

1. старый прибор не закрыт корректно;
2. новый прибор не открыт корректно;
3. нет или испорчены начальные показания;
4. текущие показания не попадают в расчет;
5. услуга не смотрит на новый прибор;
6. документ смены статусов введен неверно;
7. структура характеристик помещения искажена;
8. дубли или поврежденные данные мешают расчету.

## Что делать после локализации причины

1. не чистить все подряд по базе;
2. сначала исправить именно тот слой, который мешает этому ЛС;
3. затем повторить расчет или перерасчет;
4. только потом переходить к следующему слою:
   - живая структура характеристик помещений;
   - живые дубли ПВХ;
   - дубли документов и прочие хвосты.
